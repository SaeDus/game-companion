# Game Companion App

This directory contains the desktop application for Game Companion.

The app is built with React, TypeScript, and Tauri. It handles the user-facing workflow around selecting game data, running exporters, and saving the resulting `game-state.json` package.

## Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Tauri 2
- Lucide React

Tauri plugins currently used:

- Dialog
- File system
- Shell
- Store
- Opener

## Current structure

```text
src/
├─ features/
│  ├─ Diablo2/       # Diablo II-specific UI and types
│  └─ GameState/     # Current package-building workflow
├─ App.tsx
└─ main.tsx

src-tauri/
├─ capabilities/     # Native permissions
├─ src/              # Tauri host
└─ tauri.conf.json
```

The app is still being reorganized as the project grows, so this structure will likely change.

## What the app currently does

For the Diablo II prototype, the app can:

- Select a character save (`.d2s`)
- Select a shared stash save (`.d2i`)
- Remember those paths between sessions
- Run the Diablo II exporter
- Read its JSON output
- Show basic generation status and character information
- Build and save `game-state.json`

The game-specific parsing and formatting stays in the exporter rather than in the React or Tauri layers.

## Development

### Requirements

The current development setup requires:

- Node.js / npm
- Rust toolchain for Tauri
- .NET SDK compatible with `net10.0`
- Python 3 for Diablo II data initialization

### Install dependencies

From this directory:

```bash
npm install
```

### Run the desktop app

```bash
npm run tauri dev
```

### Build the frontend

```bash
npm run build
```

During development, the app runs the Diablo II exporter through `dotnet run` using:

```text
../exporters/diablo-2/d2-reader.csproj
```

A packaged release can replace this with compiled binaries or sidecars later.

## Local settings

Tauri's store plugin is used to save local configuration such as selected character and stash paths.

These settings are separate from the Diablo II lookup data generated by the exporter.
